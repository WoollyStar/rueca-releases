# Rueca

A Twitch and Discord bot with a panel, a mod panel and overlays for OBS, running on your Windows PC. Available in English and Spanish.

## Download

In [Releases](../../releases/latest), download `rueca-<version>-instalador.exe` and open it. Each release includes a `README.txt` (English) and a `LEEME.txt` (Spanish) with step-by-step installation instructions.

- Windows may show "Windows protected your PC" (SmartScreen) because the installer doesn't have a digital signature yet: click "More info" and then "Run anyway".
- During the installation, Node.js is downloaded from nodejs.org, so an internet connection is needed.
- The installer asks for a language at the start. You can change it later in Settings → Language, separately for the panel and for what your community sees.
- Once installed, Rueca lets you know when there's a new version and updates itself from the panel.

## Plugins

Each plugin is a separate zip in every release. Install only the ones you need from the panel: System → Modules → Install a plugin.

| Plugin | What it does |
| --- | --- |
| Quotes | Memorable lines from the stream: `!quote` reads them, and mods save new ones from chat or the panel. |
| Discord | The bot on your Discord server: slash commands, messages from rules, thanks and stream summaries. Each feature is turned on separately. |
| Donations | Cafecito and Ko-fi: alerts, credits, top donation in chat and rules. |
| Media | Images, GIFs, short videos and audio shown on screen with rewards, rules or commands. |
| Chat music | Chat requests YouTube or YouTube Music songs with a command, a reward or the request site; they play one at a time on stream. |
| Overlay editor | Create as many overlays as you like with images, videos, text, alerts, recent events and goals, and use them in OBS. |
| TTS | Reads out loud what chat asks for with rewards, commands or rules, using voices installed on your PC. |
| Chat videos | Chat requests YouTube, TikTok or Instagram videos; mods review them and they're shown on screen one at a time. |
| VTuber | Avatar actions you set up once and use in rules, rewards, Control and commands. Works with VNyan and Warudo. |

## Requirements

- 64-bit Windows 10 or 11 (x64 or ARM).
- An internet connection.
- OBS 28 or newer for the overlays.

## En español

Bot de Twitch y Discord con panel, panel de mods y overlays para OBS, que corre en tu PC con Windows. Viene en inglés y en español.

En [Releases](../../releases/latest), bajá `rueca-<versión>-instalador.exe` y abrilo. El `LEEME.txt` de cada release explica la instalación paso a paso.

- Windows puede avisar «Windows protegió su PC» (SmartScreen) porque el instalador todavía no tiene firma digital: «Más información» → «Ejecutar de todas formas».
- Durante la instalación se descarga Node.js desde nodejs.org: hace falta conexión a internet.
- El instalador pregunta el idioma al empezar. Se puede cambiar después en Configuración → Idioma, por separado para el panel y para lo que ve tu comunidad.
- Requisitos: Windows 10 u 11 de 64 bits, conexión a internet y OBS 28 o más nuevo para los overlays.
- Uso gratuito según la `LICENSE.txt` que viene con el programa (`LICENCIA.txt` es su traducción al español).
