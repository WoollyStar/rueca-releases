# Rueca

Bot de Twitch y Discord con panel, panel de mods y overlays para OBS, que corre en tu PC con Windows.

## Descargar

En [Releases](../../releases/latest), bajá `rueca-<versión>-instalador.exe` y abrilo. El `LEEME.txt` de cada release explica la instalación paso a paso.

- Windows puede avisar «Windows protegió su PC» (SmartScreen) porque el instalador todavía no tiene firma digital: «Más información» → «Ejecutar de todas formas».
- Durante la instalación se descarga Node.js desde nodejs.org: hace falta conexión a internet.
- Los plugins (música del chat, texto a voz, Discord, videos y otros) vienen aparte, un zip por plugin. Se instalan desde el panel: Sistema → Módulos → Instalar un plugin.
- Una vez instalado, Rueca avisa cuando hay una versión nueva y se actualiza desde el panel.

## Requisitos

- Windows 10 u 11 de 64 bits (x64 o ARM).
- Conexión a internet.
- OBS 28 o más nuevo para los overlays.
